Evaluation Methodology & Tolerances

1. Final Similarity Score

The system utilizes a strict binary scoring model (100% or 0%) for each parameter, based directly on the permissible limits specified by the Indian Standard (IS) codes.

Top View Output
Final Score = (Rc + Rr + Rs) / 3
Side View Output
Final Score = Average(Rs_all_pairs)

Note: If the final averaged score mathematically drops below 100% (indicating at least one parameter failed the tolerance check), the overall column is flagged as "Not Acceptable".

2. IS Code Tolerance Limits

Parameter Reference Code Permissible Tolerance
Rebar Count (Rc) Architectural Design Strict Exact Match Required.
Rebar Radius / Dia (Rr) IS 1786:2008
(Derived from unit mass variation)
  • ≤ 10 mm diameter: ± 3.5%
  • 12 – 16 mm diameter: ± 2.5%
  • > 16 mm diameter: ± 2.0%
Rebar Spacing (Rs) IS 456:2000
(Placement/Effective depth tolerance)
  • Spacing ≤ 200 mm: ± 10 mm
  • Spacing > 200 mm: ± 15 mm

3. Processing Methodology

Top View Evaluation:

Extracts the main perimeter rods, verifies the exact count (Rc), calculates the median localized pixel radius (Rr) mapped to mm, and assesses the sequential perimeter gaps (Rs) between consecutive rods in a clockwise arrangement.

Side View Evaluation:

Isolates the foreground horizontal ties (stirrups). The evaluation solely focuses on the vertical pitch spacing (Rs) between consecutive bars. The final score is the mathematical average of all calculated pair intervals; if any interval exceeds the ±10mm or ±15mm threshold, it drops to 0%, affecting the whole average.

4. Status Reporting

Acceptable (100%) The measured parameter is strictly within the allowable limit.
Not Acceptable (0%) The measurement exceeds the permissible allowance.
